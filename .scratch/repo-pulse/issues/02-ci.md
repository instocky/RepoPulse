# 02 — CI

**What to build:** A GitHub Actions workflow that runs on every push and
PR. Lints, type-checks, and tests. The cost is 20–30 minutes; the
payoff starts the next day.

**Blocked by:** 01 — Project scaffold

**Status:** ready-for-agent

- [ ] `.github/workflows/ci.yml` exists
- [ ] Workflow triggers on `push` to `main` and on every `pull_request` to `main`
- [ ] Job `lint` runs `uv run ruff check .`
- [ ] Job `typecheck` runs `uv run mypy src/`
- [ ] Job `test` runs `uv run pytest -q`
- [ ] Python version pinned to 3.11
- [ ] `uv` installed via the official `astral-sh/setup-uv@v1` action
- [ ] Caching of `~/.cache/uv` enabled for fast runs (typically <30s warm)
- [ ] All three jobs must pass before merge (branch protection on `main`)
- [ ] The architecture-doctrine test from ticket 00 runs in the `test` job
- [ ] No deploy step (deploy is ticket 14)
- [ ] The CI config itself is sanity-checked by triggering it on a draft PR
- [ ] `ruff` config: line length 100, target Python 3.11
- [ ] `mypy` config: strict on `src/repo_pulse/`, lenient on tests
- [ ] Workflow completes in <2 minutes on a warm cache
