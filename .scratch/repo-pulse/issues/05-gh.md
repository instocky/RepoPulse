# 04 — GitHub client (`gh`)

**What to build:** An HTTP client wrapping the GitHub REST API. Three methods: `fetch_starred()` returns the user's full starred list (paginated), `fetch_repo(owner, name)` returns full repo details, `fetch_latest_release(owner, name)` returns the latest release or None. 429/5xx retried with exponential backoff; 4xx (including 404) fail fast with a structured log.

**Blocked by:** 02 — Config
